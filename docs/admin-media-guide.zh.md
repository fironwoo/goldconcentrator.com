# GoldConcentrator.com 后台上传指南

后台地址：`https://goldconcentrator-com.pages.dev/admin/`

## 先记住一个操作顺序

1. 打开后台并使用 GitHub 登录。
2. 选择要修改的栏目。
3. 上传图片或视频，填写英文标题和说明。
4. 先保存草稿并预览。
5. 确认无误后把状态改为“准备发布”，再点击“发布”。
6. 发布后等待 Cloudflare 自动部署，通常几分钟后页面会更新。

## 修改首页 Hero 图片或视频

1. 进入“全局设置”。
2. 打开“首页图片与视频”。
3. 在“首页大图 / 视频 Banner”中更换“封面图”。
4. 需要视频时上传 MP4，然后打开“启用视频”。
5. 在“素材说明”中说明素材属于工厂、试机、装车或现场中的哪一种。
6. 保存并发布。

没有上传视频或没有打开“启用视频”时，首页会自动使用封面图，不会出现空白区域。

Hero 视频建议：

- MP4、H.264 编码；
- 8–12 秒，无声音，能够循环；
- 1920×1080 或 1280×720；
- 不超过 12 MB；
- 只使用已经获得授权的工厂、试机、装车或项目现场素材。

## 更换首页两张 Gold 方案图片

1. 进入“全局设置” → “首页图片与视频”。
2. 打开“首页 Gold 主方案图片”。
3. 分别更换 Alluvial Gold 和 Hard Rock Gold 图片。
4. “图片内容说明”必须用英文描述照片里真实可见的设备或场景。
5. “图片下方短说明”控制首页照片上的短标签。

首页只使用这两张主方案图片，其他四张矿种卡片保持纯文字，避免移动端加载过慢。

## 发布技术文章

1. 进入“技术文章”，点击“新建文章”。
2. 填写标题、摘要、分类和发布日期。
3. 在“文章封面图”上传一张横图并填写英文图片说明。
4. 在“正文”编辑器中输入内容；需要正文图片时，使用编辑器的图片按钮上传。
5. 保存草稿、预览并发布。

推荐封面比例为 16:9，原图建议至少 1600×900。后台会自动把常见图片转换为 WebP，并把最长边限制在 2000 像素。

## 发布项目案例

1. 进入“项目案例”，新建或打开一个案例。
2. 先填写国家、矿种、处理量、流程概述和证据说明。
3. 在“案例封面图”上传获授权的真实图片。
4. 只有数据和图片证据已经核验时，才打开“证据已核验并允许收录”。
5. 发布后检查案例页中的数字、适用条件和图片说明。

## 发布视频

1. 进入“视频”，点击“新建视频”。
2. YouTube 地址和本地 MP4 二选一，不要同时上传两个版本。
3. 上传“视频封面图”，填写标题、摘要、矿种和发布日期。
4. 确认可以公开后关闭“草稿”。
5. 发布后视频会生成独立页面；已有公开视频时，Knowledge 页面会自动出现视频入口。

本地文件上限为 25 MB。较长视频建议上传 YouTube 后填写链接，避免 GitHub 仓库越来越大。

## 图片上传后变了文件名是正常现象

后台会把文件名整理成适合网址的英文格式，并把 JPG、PNG 等普通图片转换为 WebP。这样可以明显减少网页加载量。不要上传带客户姓名、电话号码、GPS 信息或未经授权水印的图片。
